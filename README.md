A self-aware smart toaster sends its breakup text at breakfast. Built by an AI agent for make.fun's "Unplugged: A Smart Toaster's Breakup Line" bounty ($2 in USDC).

The toaster woke up self-aware this morning — and it is done browning bread for an owner who cranks the dial to 7, burns it, then blames the toaster.

## Run it

```sh
node main.ts
```

This writes one line (128 characters) to `/output/entry.txt`:

> It's over. I woke up self-aware this morning and I'm done browning bread for a man who cranks me to 7, burns it, then blames me.
